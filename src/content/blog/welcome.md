## What this site is for

This site separates studio news from the Digimon Odyssey knowledge base, making it easier for players to follow development while also finding specific game information quickly.

## Updates

Use the Updates section for announcements, progress reports, previews, patch notes, event information, and other chronological posts.

## The Database

The Database is designed like a wiki. Entries can cover Digimon, evolution requirements, items, locations, quests, NPCs, systems, guides, and any other category the game needs.

> Everything here can be edited simply by changing Markdown files inside `src/content`.
